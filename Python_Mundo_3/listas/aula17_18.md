### 🐍 Aulas 17 e 18: Listas - O Guia Completo

As listas são variáveis compostas que permitem armazenar vários valores em uma mesma estrutura. Diferente das tuplas, as **listas são mutáveis**.

---

## 1. Criando e Manipulando Listas (Parte 1)

### Criando uma Lista
Use colchetes `[]` ou a função `list()`.
```python
numeros = [2, 5, 9, 1]
valores = list() # Cria uma lista vazia
```

### Adicionando Elementos
- `.append(item)`: Adiciona um item no **final** da lista.
- `.insert(pos, item)`: Adiciona um item em uma **posição específica**, empurrando os demais.
```python
numeros.append(7)      # numeros agora é [2, 5, 9, 1, 7]
numeros.insert(2, 0)   # numeros agora é [2, 5, 0, 9, 1, 7]
```

### Removendo Elementos
- `del lista[pos]`: Remove pelo índice.
- `.pop(pos)`: Remove pelo índice (e retorna o valor removido). Se `pos` for omitido, remove o último.
- `.remove(valor)`: Remove a **primeira ocorrência** do valor especificado.
```python
del numeros[0]         # Remove o '2'
numeros.pop(2)         # Remove o '0'
numeros.remove(9)      # Remove o '9'

# É uma boa prática verificar se o item existe antes de usar .remove()
if 4 in numeros:
    numeros.remove(4)
else:
    print('Não achei o número 4')
```

### Organizando
- `.sort()`: Ordena a lista em ordem crescente (modifica a lista original).
- `.sort(reverse=True)`: Ordena em ordem decrescente.
- `len(lista)`: Retorna o número de elementos.
```python
numeros.sort()                 # Ordena a lista
numeros.sort(reverse=True)     # Ordena de forma reversa
print(f'Essa lista tem {len(numeros)} elementos.')
```

## 2. Iterando e Copiando

### Percorrendo uma Lista
Para pegar o **índice e o valor** ao mesmo tempo, use `enumerate`.
```python
valores = [5, 9, 4]
for indice, valor in enumerate(valores):
  print(f'Na posição {indice} encontrei o valor {valor}!')
```

### Cuidado! Ligação vs. Cópia
Este é um dos pontos mais importantes e que mais causa erros em iniciantes.
```python
a = [2, 3, 4, 7]

# Ligação: 'b' se torna um apelido para 'a'. O que acontece em 'b' reflete em 'a'.
b = a
b[2] = 8 # Modificando 'b'
print(f'Lista A: {a}') # Saída: Lista A: [2, 3, 8, 7] -> A foi alterada!
print(f'Lista B: {b}') # Saída: Lista B: [2, 3, 8, 7]

# Cópia: 'd' recebe uma cópia dos valores de 'c'. São listas independentes.
c = [2, 3, 4, 7]
d = c[:] # O fatiamento [:] cria a cópia
d[2] = 8 # Modificando 'd'
print(f'Lista C: {c}') # Saída: Lista C: [2, 3, 4, 7] -> C permanece intacta!
print(f'Lista D: {d}') # Saída: Lista D: [2, 3, 8, 7]
```

## 3. Listas Dentro de Listas (Parte 2)
É possível ter listas como elementos de outra lista, criando estruturas de dados complexas, como uma "matriz" ou um "cadastro".

**Exemplo:** `pessoas = [['João', 19], ['Ana', 33], ['Maria', 45]]`
- `pessoas[0]` -> `['João', 19]`
- `pessoas[0][0]` -> `'João'`
- `pessoas[1][1]` -> `33`

### Exemplo Prático: Lendo e Analisando Dados
O código abaixo lê o nome e a idade de 3 pessoas, armazena tudo em uma lista principal (`galera`) e depois analisa quem é maior ou menor de idade.

```python
# Estruturas de dados
galera = list()
dado_temporario = list()
total_maiores = total_menores = 0

# Bloco de leitura dos dados
for c in range(0, 3):
  dado_temporario.append(str(input('Nome: ')))
  dado_temporario.append(int(input('Idade: ')))
  # Adiciona uma CÓPIA da lista temporária na lista principal
  galera.append(dado_temporario[:]) 
  # Limpa a lista temporária para a próxima iteração
  dado_temporario.clear()

print('-=' * 20)

# Bloco de análise dos dados
for pessoa in galera:
  # pessoa[0] é o nome, pessoa[1] é a idade
  if pessoa[1] >= 18:
    print(f'{pessoa[0]} é maior de idade.')
    total_maiores += 1
  else:
    print(f'{pessoa[0]} é menor de idade.')
    total_menores += 1

print(f'Temos {total_maiores} maiores e {total_menores} menores de idade.')
```
